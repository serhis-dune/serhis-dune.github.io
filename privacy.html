Политика конфиденциальности

Дата обновления: 11 октября 2026 года

Эта политика описывает использование данных в личном приложении Dune NAS Player (сервер YouTubeNAS и плагин Dune), а также на его информационном сайте. Приложением управляет владелец домашнего NAS.

Какие данные используются

  • OAuth-токены Google, необходимые для чтения данных YouTube с разрешения пользователя и обновления доступа.
  • Идентификатор и название собственного канала, список подписок, сведения о каналах, названия и идентификаторы видео, изображения и другие метаданные, получаемые через YouTube Data API.
  • Локальная история просмотра, список «Смотреть позже», настройки приложения и позиции воспроизведения.
  • Технические журналы и временные файлы воспроизведения для работы и диагностики приложения.

Приложение не запрашивает пароль Google, доступ к Gmail, контактам или Google Drive. Авторизация предоставляется через страницы Google.

Для чего нужны данные

Данные используются для отображения подписок и сведений о видео, формирования ленты, воспроизведения выбранного пользователем контента и сохранения локального состояния. Доступ Google ограничен чтением YouTube; изменение аккаунта не запрашивается.

Где хранятся данные

Токены и данные приложения сохраняются на домашнем NAS; часть настроек и позиций просмотра может сохраняться на медиаплеере Dune. Данные не загружаются на этот информационный сайт или в его репозиторий. Личная резервная копия NAS также может содержать эти данные и хранится самим владельцем.

Токены сохраняются для работы авторизации до выхода из аккаунта, утраты доступа или удаления. Локальные списки и настройки сохраняются до их отдельной очистки владельцем. Кэш и временные файлы очищаются в соответствии с настройками приложения.

Обращения к внешним сервисам

  • Google и YouTube: запросы авторизации, чтения YouTube Data API, получения метаданных, изображений и выбранного видео. Эти сервисы получают сведения, необходимые для запроса, включая IP-адрес подключения.
  • SponsorBlock: при включённой функции пропуска спонсорских вставок сервер отправляет идентификатор выбранного видео для получения границ сегментов. Сервис видит IP-адрес запроса. OAuth-токены Google ему не передаются.

Данные аккаунта не продаются, не используются для рекламы, оценки кредитоспособности или обучения моделей машинного обучения. Доступ к ним ограничен функциями личного приложения и действиями его владельца.

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ и удалить данные

В приложении можно выбрать «Выйти из аккаунта»: локальные OAuth-токены и кэш Google удаляются. Разрешение приложения можно отдельно отозвать в настройках подключений Google Account. Для удаления локальной истории, списков, настроек и резервных копий владелец отдельно очищает соответствующие данные на NAS и Dune. Выход из аккаунта не удаляет автоматически все локальные списки.

Этот информационный сайт

Страницы не содержат аналитических скриптов, рекламных трекеров, форм сбора данных или механизмов авторизации. При размещении на GitHub Pages инфраструктура GitHub обрабатывает технические данные посещения, включая IP-адрес, согласно политике конфиденциальности GitHub.

Контакт

Вопросы о данных личного приложения можно направить владельцу NAS через контакт поддержки, указанный на экране согласия Google для этого приложения. Пользователь и владелец NAS в данном проекте — один человек.
